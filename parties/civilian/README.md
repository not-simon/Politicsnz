# The Civilian Party

| | |
|---|---|
| **Status (Oct 2026)** | **Deregistered** at its own request on 5 May 2015 |
| **Founded** | Announced June 2013 by satirist Ben Uffindell (editor of *The Civilian* satirical website); registered 11 August 2014 |
| **Ideology** | Satirical/joke party (e.g. "a llama to every child living in poverty", independence from Hamilton) |
| **Seats** | None |

## History

The party drew criticism in 2014 for receiving $33,635 of broadcasting funding; John Key quipped "the biggest joke's
on us, the taxpayer". Uffindell replied that other "joke parties" were getting funding too. It won 1,096 votes (0.05%)
in 2014 and stood no electorate candidates. [1][2]
